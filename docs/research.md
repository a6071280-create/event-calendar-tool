## Step 2〜4: 情報源ごとの自動取得可否

| 情報源 | API | 自動取得 | 根拠 |

| 店舗公式サイト | サイトによる | **条件付き可** | サイトごとに robots.txt / 利用規約を確認。許可される範囲で低頻度・UA明示のポーライトアクセスに限定。collector の robots.txt チェッカーが機械的に遵守を強制する。 |

| その他情報サイト（みんパチ等） | なし | サイトごとに要確認 | 個別確認まで無効のまま。 |

### 結論（コンプライアンス方針）

1. **P-WORLD の自動取得は行わない。** 店長が目視確認し、アプリの「手動クイック登録」（情報源名・URL付き、数タップ）で取り込む。取り込み後の重複排除・履歴管理・差分検知はすべて自動。
2. **DMMぱちタウンは許諾取得により自動収集を有効化（2026-08-11）。** 申請した条件（1日3回程度・佐久市内6店舗の店舗ページのみ・UA明示・社内利用・出典表記）の範囲内でのみ収集する。許諾条件が変わった場合は `data/site-sources.json` の `dmm-ptown-*` を `enabled: false` にすること。
3. **自動収集は許可された情報源のみ**。collector はアダプタ方式で、`data/sources.json` の `enabled` フラグと robots.txt チェックを通過した情報源だけを取得する。店舗公式サイトについて許可が確認できたものから順次有効化する。

## アーキテクチャ決定

- **DB**: リポジトリ内 JSON（`data/db/`）。GitHub の履歴 + レコード内の変更履歴（`changes[]`）で「削除しない蓄積」を実現。サーバー不要。
- **自動更新**: GitHub Actions cron（1日3回, JST 6/12/18時）で collector を実行し、変更があればコミット → GitHub Pages が自動再デプロイ。
- **フロントエンド**: 既存の React + Vite アプリに「佐久市」タブ（日付×店舗マトリクス）を追加。`public/data/dataset.json` を読み込む。
- **差分検知**: AI 予測ではなく過去実績の機械的集計（`src/saku/lib/patterns.ts`）。閾値は `data/settings.json` で変更可能。

## 制約事項（サンドボックス）

本開発環境からは対象サイトへの直接アクセスがネットワークポリシーで遮断されているため、実データの自動取得検証は未実施。初期データは仕様の動作を実証するサンプルデータ（`demo` フラグ付き）で投入しており、実運用データは手動登録および許可済みアダプタ経由で置き換わる。
